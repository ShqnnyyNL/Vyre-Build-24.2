# Changelog

Public-facing Vyre release notes. Internal implementation details are intentionally omitted.

## 3.9.7.12 — Menu & Profile Polish

### Navigation
- Continued separation of player-specific progression systems from survival navigation.
- Player-oriented destinations are consolidated around Profile.
- Main Menu remains focused on survival-facing destinations.
- Black Market remains a dedicated economy/survival destination rather than part of Cosmetics.

### UX
- Continued consistency work across Profile-related interfaces.
- Navigation and Back behavior remain part of the shared menu design language.
- Bedrock/mobile usability remains an active polish target.

### Stability direction
- Compatibility, performance, configuration safety and UX polish take priority over unrelated feature expansion.
- Existing player/server data should be backed up before every production update.

> Detailed proprietary implementation changes are not published in this repository.
